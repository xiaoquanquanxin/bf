## 最佳方案：Supervisor Agent + Tool Dispatch Pattern

```txt
┌─────────────────────────────────────────────────────────────┐
│  用户输入: "查询用户数据，然后画出信息可视化，最后汇总结果"    │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
        ┌──────────────────────────────┐
        │    Supervisor Agent          │  ← 唯一的决策者
        │  (持有对话历史和上下文)       │
        │                              │
        │ "理解任务，动态编排执行"     │
        └──────────────────┬───────────┘
                      │ (LLM 决策：需要调用哪个 agents)
          ┌───────────┼────────────┬──────────────┐
          ▼           ▼            ▼              ▼
    ┌─────────┐ ┌────────┐ ┌──────────┐  ┌────────────┐
    │ Query   │ │ Chart  │ │ Output   │  │ Composite  │
    │ Agent   │ │ Agent  │ │ Info     │  │ Data Agent │
    │         │ │        │ │ Agent    │  │            │
    │ (独立)  │ │(独立)  │ │ (独立)   │  │ (独立)     │
    └─────────┘ └────────┘ └──────────┘  └────────────┘
          │           │            │              │
          └───────────┼────────────┼──────────────┘
                      │ (返回结果)
                      ▼
        ┌──────────────────────────────┐
        │    Supervisor Agent          │
        │  (汇总、继续对话、下一步)    │
        └──────────────────────────────┘
                      │
                      ▼
              ┌────────────────┐
              │   最终输出     │
              └────────────────┘
```
